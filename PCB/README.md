# PCB Design

This folder contains the printed circuit board (PCB) design files for the multi-output laboratory power supply project, developed using Altium Designer.

## Folder Structure

* **Trunk/**: Contains the Altium Designer project files, schematics, PCB layout, and other related design documents.
* **Libraries/**: Contains the electronic component libraries created or customized for the project, including schematic symbols and PCB footprints.

## Project Overview

The PCB will integrate the electronic stages required to provide the following regulated outputs:

* +12 V DC, 5 A
* +5 V DC, 5 A
* +3.3 V DC, 3 A
* -12 V DC, 1 A
* Adjustable output from 1.25 V to 15 V DC, 3 A

The detailed design and component selection will be developed according to the project requirements and the available laboratory transformer specifications.
